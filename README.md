# آثار بلادي — وسائل تعليمية

وسائل تعليمية لدرس «آثار بلادي» — التربية للمواطنة، الصف الثالث الابتدائي (مملكة البحرين).

- **القصة التفاعلية: دلّوني يبحث عن عائلته** — الصفحة الرئيسية.
- **لعبة: سفينة الآثار** — في المسار `/game`.

الهدف: أن يصنّف التلميذ المواقع الأثرية المعطاة له في مملكة البحرين إلى معابد، ومدافن، ومساجد، وقلاع.

مقرر TCED 411 — كلية محمد جابر الأنصاري للمعلمين.
